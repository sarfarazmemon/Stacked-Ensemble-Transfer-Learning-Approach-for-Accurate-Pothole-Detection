SETL_Pothole: Stacked Ensemble Transfer Learning for Accurate Pothole Detection

SETL_Pothole is a deep learning-based framework for automated pothole detection in road images using Stacked Ensemble Transfer Learning. The proposed approach combines the complementary feature-learning capabilities of Xception and EfficientNetB0 to achieve accurate, robust, and reliable pothole classification.

The framework addresses the limitations of conventional road inspection methods, which are often time-consuming, labor-intensive, and difficult to scale. By leveraging pretrained convolutional neural networks and ensemble learning, SETL_Pothole provides an efficient computer-vision solution for automated road-condition monitoring.

Key Features

Stacked Ensemble Transfer Learning (SETL) using Xception and EfficientNetB0

Automated pothole and non-pothole classification

Transfer learning with pretrained deep learning architectures

Training-set data augmentation to improve sample diversity and generalization

Comparative evaluation against:

Voting Ensemble Transfer Learning (VETL)

Bagging Ensemble Transfer Learning (BETL)

Evaluation using accuracy, precision, recall, F1-score, specificity, and confusion matrix

Designed for potential applications in intelligent transportation systems and automated road inspection

Datasets

Two datasets were utilized to evaluate the proposed framework:

Road Anomaly Detection (RAD) Dataset
A custom dataset generated by extracting relevant road frames from videos.

Mendeley Public Dataset
A publicly available road/pothole dataset used to complement the custom dataset and evaluate the generalizability of the proposed approach.
